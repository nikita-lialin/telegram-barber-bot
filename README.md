# telegram-barber-bot

Telegram-бот-визитка парикмахерской: мастера, услуги и цены, фото работ, график, адрес и быстрая связь для записи.

Стек: TypeScript, Node.js, [grammY](https://grammy.dev). Языки: русский и английский.
